# Inventory-stock-balance-dashboard

 PROJECT OVERVIEW
This project analyzes inventory data to understand stock levels, inventory value distribution,
warehouse performance, and product availability. The dashboard was created to help decision
making monitor inventory performance, identify high value stock, identify low quantity stocks,
and detect potential stock shortage risks.

 TOOLS USED
1. Microsoft Execl : For data review and initial cleaning
2. Power Query : For data transformation and preparation
3. SQL : For data storage, querying, and data validation
4. Power BI Desktop : For data modeling, data visualization, dashboard development, and
interactive analysis

 BUSINESS QUESTIONS ANSWERED
1. What is the total inventory quantity and total inventory value?
2. How many warehouses are holding inventory?
3. Which warehouse has the highest stock quantity?
4. Which items contribute the highest inventory value?
5. Which warehouse holds the highest inventory value?
6. Which items have the lowest available quantity?
7. Which item group contributes the most inventory values?
8. 
 KEY INSIGHTS
1. The business manages inventory across 69 warehouses.
2. Food floor ONL has the highest stock quantity, indicating it holds the largest volume of
inventory among all warehouse.
3. Insecticide floor has the highest inventory value, showing that the most financially
significant stock is concentrated there
4. Baygon is the item with the highest balance value, making it the most valuable single
inventory item.
5. SC Johnson is the item group with the highest inventory value contributions.
6. Kiski Jumbo has the lowest quantity and may require stock monitoring to avoid potential
shortage

 RECOMMENDATIONS
1. Monitor low stock items such as kiski jumbo and establish appropriate reorder levels.
2. Review high value inventory such as baygon regularly to reduce risk associated with
excess stock or tied up capital
3. Focus inventory management efforts on high value item groups like SC Johnson
4. Use warehouse level analysis to improve stock distribution and avoid overstocking in
certain locations.
